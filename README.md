# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/tayyabawaseem/EarthScape.git
```

## Navigate

```bash
cd EarthScape
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

Open

```text
http://localhost:3000
```
